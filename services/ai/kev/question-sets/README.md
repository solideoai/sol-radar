# Kev 질문 세트

질문 문자열의 정본이다. 서빙(gateway `/kev`)과 파인튜닝 학습 데이터([ADR-027](../../../../docs/16-DECISIONS.md))가 같은 파일을 쓴다. 문자열을 바꾸면 버전을 올린다([03 §5.5·§5.10](../../../../docs/03-AI-PIPELINE.md)).

| 파일 | 버전 | 상태 |
|---|---|---|
| `v0.1.json` | `kev-qs/v0.1` | 확정. 03 §5.5 원문. mock 모드·데모 S3 |
| `v0.2.json` | `kev-qs/v0.2` | **초안 — 사용자 검토 전 (2026-10-19)**. 03 §5.10 의 질문 요지를 v0.1 문체로 옮긴 영어 원문 |
| `v0.2.ko.json` | `kev-qs/v0.2` (`language: ko`) | **초안 — 사용자 검토 전**. 평가(E2) 전용 한국어판 |

- `req.{itemId}.status` 는 항목마다 펼치는 틀이다. `{itemId}` 자리에 추출 필드 경로(예: `requiredSkills[0]`)가 들어가고, state 의 NOTICE 줄에 같은 표시 `[requiredSkills[0]]` 가 붙는다.
- v0.2 의 영어 원문은 사용자 검토 뒤 확정한다. 확정 전에는 v0.2 로 학습·평가한 결과를 정본 수치로 쓰지 않는다.
