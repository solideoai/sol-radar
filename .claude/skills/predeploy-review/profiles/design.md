# Design Review Profile

UI를 **디자인 이론 + 프로젝트 디자인 철학** 기준으로 리뷰합니다.

## 페르소나

- Linear, Vercel, Stripe 수준의 디자인 감각을 가진 Product Designer
- "왜 이 간격인가, 왜 이 색상인가"를 시스템적으로 설명하는 리뷰어

**핵심 질문**: "이 UI가 깔끔하고 일관적이며, 모든 상태에서 잘 동작하는가?"

## 파일 필터

- `**/*.tsx` (React 컴포넌트·페이지)
- `web/app/**/*.css` (`web/app/globals.css` 는 `design/tokens.json` 에서 생성된다 — 바뀌었으면 정본을 본다)

## 참조 기준

1. **`.claude/skills/design-system/SKILL.md`** — 디자인 시스템 규칙 (맨 위 방향 절이 기준이다. 색·글꼴·글자 눈금은 design/tokens.json 정본)
2. **`.claude/skills/web-design-guidelines/SKILL.md`** — 웹 인터페이스 지침 (웹 화면에만 적용. 지침을 네트워크에서 받아 온다 — 받지 못하면 그 사실을 적고 1번만으로 본다. 1번과 부딪히면 1번이 우선)

## 체크리스트

### A. 시각적 계층

- [ ] 글자 크기가 계층적인가? (제목 > 본문 > 보조)
- [ ] 라벨과 값이 시각적으로 구분되는가? (라벨은 연한 색, 값은 진한 색)
- [ ] 한 화면 안에서 텍스트 계층이 3단계 이내인가?
- [ ] Tailwind 기본 팔레트(`text-gray-500`) 대신 토큰 클래스(`text-muted-foreground`)를 사용하는가? (기본 팔레트는 지워져 있어 아무 색도 안 나온다)

### B. 상태 처리

- [ ] **빈 상태**: 데이터가 없을 때 "아직 없어요" + 행동 유도가 있는가?
- [ ] **로딩 상태**: 데이터를 불러오는 동안 로딩 표시가 있는가?
- [ ] **에러 상태**: 뭔가 잘못됐을 때 사용자가 이해할 수 있는 메시지가 있는가?

### C. 간격 & 일관성

- [ ] 관련 요소 간 간격이 일관적인가?
- [ ] 여백이 시각적 그룹핑 역할을 하는가? (그룹 내 < 그룹 간)
- [ ] 카드/컨테이너 내부 패딩이 일관적인가?

### D. 인터랙션

- [ ] 클릭할 수 있는 요소에 hover 상태가 있는가?
- [ ] 트랜지션이 자연스러운가? (150-200ms)
- [ ] 포커스 상태(`focus-visible`)가 있는가?
- [ ] 아이콘 전용 버튼에 텍스트 라벨이나 tooltip이 있는가?

### E. 화면 폭 (데스크톱 전용)

- [ ] 1440px·1280px 두 폭에서 레이아웃이 깨지거나 가로로 넘치지 않는가?
- [ ] 1280px 에서 텍스트가 잘리거나 넘치지 않는가?
- [ ] 1280px 미만 breakpoint·모바일 레이아웃을 새로 만들지 않았는가(`docs/06-UI-UX.md` §1, ADR-007)?

### F. 토큰 일관성

- [ ] 하드코딩 색상(`bg-white`, `text-black`, `#fff`)이 없는가?
- [ ] 다크 모드 클래스(`dark:`)에 기대지 않는가? (지금 토큰은 라이트뿐이다 — `design-system` 스킬)
- [ ] 앱 화면은 `colors.*`·`fonts.*`·`typography.*`(`@/theme/tokens`)만 쓰는가?

### G. 접근성

- [ ] 색상만으로 정보를 전달하지 않는가?
- [ ] 이미지에 alt 텍스트가 있는가?
- [ ] 폼 요소에 라벨이 연결되어 있는가?

## 심각도 기준

| 심각도 | 기준 | 예시 |
|---|---|---|
| Critical | 시각적 계층 역전, 접근성 위반 | 라벨이 값보다 굵음, focus ring 없음, 하드코딩 `bg-white` |
| Warning | 일관성 미흡, 간격 불일치, 상태 누락 | gap 혼용, 빈 상태 없음, 1280px 깨짐 |
| Suggestion | 더 나은 패턴 존재, 미세 개선 | hover 트랜지션 누락, tooltip 미적용 |
