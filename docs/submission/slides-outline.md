# 발표 슬라이드 구성안

12장이다. 11장은 사용자가 정한 주제 11개이고, 11장째에 [[18-HACKATHON|18 해커톤]] §7 정직성 표를 그대로 넣는다(18 §10 순서 "§1 → §2 → §3.2 → 데모 → §7 → 이후 계획"). 수치는 정본에 있는 것만 쓴다. 가설은 "가설"이라고 적고, 측정 전 칸은 비워 둔다. 구현되지 않은 화면은 캡처하지 않는다.

데이터 상태 값: **확정**(정본에 있고 바뀌지 않음) / **측정 뒤 채움**(실험·조사 결과) / **캡처 불가**(화면 미구현, 담당 작업 뒤) / **재확인**(발표 전 원문 확인).

## 장별 주의

- 4·5·7·8장의 화면 캡처는 [[17-CLAUDE-IMPLEMENTATION|17 구현 규칙]] 파일명 규칙(`YYYYMMDD-phaseN-<route>-<state>-<width>.png`, 1440 기본)을 따르고 `docs/evidence/`에서 가져온다. 캡처가 없으면 와이어프레임이라고 적는다.
- 7장은 `limitations.md` §4의 네 문장 중 외부 의존성 컷 결과에 맞는 하나만 쓴다. 녹화·fixture 결과를 live라고 쓰지 않는다.
