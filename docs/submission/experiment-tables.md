# 실험 결과 표 (빈 틀)

두 표 모두 **측정 전. 값 없음.** 빈 칸에 추정값을 넣지 않는다. 지표 정의는 [[21-MODEL-TRAINING|21 모델 학습]] §4.3, 비교 대상은 §4.2, 임팩트 지표는 [[01-PRD|01 PRD]] 성공 측정이다. 표본이 작으므로 모든 값에 표본 수와 부트스트랩 95% 신뢰구간을 함께 적고, "예비 검증이며 일반화된 성능을 입증하지 않는다"를 표 아래에 남긴다.

## (b) 임팩트 예비 실험 n=3 (X2)

**측정 전. 값 없음.**

절차: 실제 공고 3건 → 사람이 기존 방식으로 분석(참가자격 · 기술 적합도 · 인력 적합성 · 위험 요소 기록, 시간 측정) → 같은 공고를 SOL RADAR로 분석(사람 최종 확인 시간 포함 총 소요 시간) → 누락 · 수정 · 일치율 · 유용성 비교. 검증자가 외부 실무자가 아니면 "개발자 자체 검증"으로 적고 실무자 검증이라 쓰지 않는다.
