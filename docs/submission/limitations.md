# 기술적 한계·미완성 항목·실행 모드 구분

심사위원이 "어디까지가 실제이고 어디까지가 mock인가"를 묻기 전에 먼저 답하는 문서다. 정본은 [[18-HACKATHON|18 해커톤]] §7 정직성 표와 [[16-DECISIONS|16 ADR]] 미결정 표다. 2026-10-19 기준이며, 10-21 컷 결정 뒤 §4를 한 갈래로 확정한다.

## 1. 정직성 표 요약 (18 §7)

| 영역 | `live` | `fixture` | `mock` |
|---|---|---|---|
| 공고 | 실제 나라장터 공고(`is_demo=false`) | 가상 fixture 20건(`DEMO` 배지) | 가상 fixture 20건 |
| 첨부·파싱 | 실제 첨부 allowlist 다운로드·파싱(검증된 형식만) | fixture 샘플 | fixture 샘플 |
| 회사 프로필 | **가상 솔리데오**(모든 모드, "가상 회사 프로필로 분석" 배지) | 가상 솔리데오 | 가상 솔리데오 |
| Qwen 추출·설명 | 회사 GPU 서버 실추론 | 실추론 | 고정 응답 |
| Kev | 실추론, 참고 지표만, `UNCALIBRATED` | 실추론 | 고정 응답(`kev-qs/v0.1`) |
| mock 자동 대체 | 금지(켜면 기동 거부) | `AI_FALLBACK_TO_MOCK=true`일 때만, 배너 표시 | 해당 없음 |

모드와 무관하게 실제 구현인 것: 수집·정규화·revision·변경 감지, 자격 판정·SOL Score·결정 정책, 인앱 알림, 테넌트 격리(RLS). 골든 94/72/68은 `mock`에서만 단언한다.

## 2. 미검증 (2026-10-19 기준)

| 항목 | 상태 | 어디서 확인 |
|---|---|---|
| Kev의 한국어 입찰 도메인 성능. 모델 카드 `language: en` | 미측정. 운영은 영어 템플릿 state만, 한국어 state는 평가 전용(E2) | 16 미결정 2번, [[03-AI-PIPELINE\|03 AI 파이프라인]] §5.6 · §5.11 |
| 나라장터 실제 API 응답(서비스키로 받은 것) | 없음. 명세로만 확인 | 16 미결정 1번, P0-0 ① |
| g2b 첨부 자동 다운로드(로그인·약관) | 미검증 | 16 미결정 16번, P0-0 ② |
| 회사 GPU 서버 접속·A40 × 2 점유 가능 범위·Kev-9B 실제 VRAM(문서 17 GB vs 21.9 GB) | 미검증 | 16 미결정 3 · 17번, P0-0 ③ |
| HWP·HWPX·PDF 파서 선택과 품질 | 후보 조사만. 실제 RFP 샘플 비교 전 | 16 미결정 4 · 20번 |
| 첨부 원문(공고문·제안요청서)의 저작권·학습 사용 권리 | 미확인. 내부 분석만, 원문은 증거에 넣지 않음 | 16 미결정 18번 |
| 면허제한 여러 행의 AND/OR | 미확인. 여러 행이면 `NEEDS_REVIEW`(`AMBIGUOUS_MATCH`) | 16 미결정 19번 |
| Supabase Auth 세부 설정값(토큰 만료·시도 제한) | 미확인. 값을 적지 않음 | 16 미결정 10번 |
| 점수 가중치 30/25/20/15/10과 임계값 75/50 | 초기 가정. 백테스트 전 | [[08-SCORING\|08 점수]] §2, 16 미결정 7번 |
| 시간 절감 30분 → 10분 | 가설. 측정 전 | [[01-PRD\|01 PRD]] 성공 측정, `experiment-tables.md` (b) |

## 3. 미완성·범위 밖

**해커톤 안 미완성(2026-10-19)**: 공고 스키마·수집·`/extract`·`/kev`·`/explain`·규칙 엔진(인력 FTE 함수만 있음)·`/dashboard`·`/bids`·`/bids/[id]`·알림·`pnpm demo:reset`·외부 연동·평가 하네스. 진행 상태는 [[PROGRESS|진행 상황]].

**확장 컷으로 이월**(핵심 컷 green 뒤에만): 조직도·직원 목록 데모 노출, 설정 조직 탭, 인력 배치 시뮬레이션, 직원 편집, `/ops`, 사전규격·발주계획 단계 연결(P0-8), 전체 평가셋·학습셋 내보내기(P0-9~P0-11), S5 변경 감지 장면.

**범위 밖(해커톤 이후 포함)**: 결제·구독, 모바일 레이아웃·네이티브 앱, 자동 투찰, 승률·낙찰 확률 예측, 카카오톡 실발송, Kev-9B LoRA 학습, hosted 모델 API·클라우드 GPU 임대(승인 전), ERP 실연동.

**하지 않는 것**: mock 자동 대체(기본), 원본 데이터 위조, 녹화·fixture 결과를 live로 표시, 정보 부족을 미충족으로 판정, Kev가 자격·점수·권고를 바꾸는 경로.

## 4. 10-21 컷 결과별 발표 문장 (하나만 쓴다)

10-21 저녁 C1 결과로 S-LIVE 장면이 네 갈래 중 하나로 정해진다. 발표·슬라이드 7장·영상 컷 9에서는 해당 문장만 쓰고, 나머지는 지운다.

| 갈래 | C1 결과 | 발표에서 말할 문장 |
|---|---|---|
| A | 공공 API 정상, GPU 정상 | "이 화면은 나라장터에서 실제로 수집한 공고를 회사 GPU 서버의 Qwen3.5-9B와 Kev-9B로 분석한 결과입니다. 회사 프로필은 가상이고, 실행 모드는 live입니다. 실행 로그는 증거 폴더에 있습니다." |
| B | 공공 API 정상, GPU 불가 | "이 화면은 나라장터에서 실제로 수집한 공고입니다. 모델 서버에 연결하지 못해 규칙 기반 자격 판정과 점수만 있는 PARTIAL 결과이고, AI 추출과 Kev 참고 지표는 비어 있습니다. mock으로 대체하지 않았습니다." |
| C | 공공 API 불가, GPU 정상 | "공공 API 호출이 막혀 실제 공고 대신 검증된 가상 공고(fixture)를 썼습니다. 분석은 회사 GPU 서버의 실제 모델 추론이고, 실행 모드는 fixture입니다. 가상 공고라는 뜻으로 DEMO 배지가 붙어 있습니다." |
| D | 둘 다 불가 | "오늘 시연은 가상 공고와 고정 AI 응답(mock 모드)입니다. 실제 API 응답·GPU 연결은 확보하지 못했고, 그 사실과 시도 기록을 증거 폴더에 그대로 남겼습니다. 실제 결과를 보여 드리지 못한 것은 저희 한계입니다." |

어느 갈래든 머리말 "실행 모드"와 분석 패널 "AI: …" 표시가 화면에 보여야 하고, 사전 녹화를 쓰면 "녹화"라고 밝힌다.

## 5. 데모 장애 대체 경로 (요약, 정본은 19 §5에 반영 예정)

| 장애 | 대체 | 화면에 보이는 것 |
|---|---|---|
| 인터넷 연결 실패 | 로컬 Supabase CLI(`pnpm db:start`) + `pnpm demo:reset`, 리허설로 확인 | 실행 모드 그대로, 데이터 출처 로컬 |
| 공공 API 장애·일일 한도 | `fixture` 모드로 전환(env + 재시작) | "실행 모드: fixture", `DEMO` 배지 |
| GPU 서버 접속 실패 | `mock` 모드로 전환하거나 사전 완료 run 조회 | "AI: mock" 또는 저장된 run의 `run_mode` |
| Supabase 클라우드 장애 | 로컬 CLI 전환 | 위와 같음 |
| 첨부 다운로드 실패 | 그대로 시연 | `DOCUMENT_DOWNLOAD_FAILED` 배지, 관련 자격 "확인 필요" |
| 추론 시간 초과 | 그대로 시연 | `PARTIAL` 배너, `RULES_ONLY` |

자동 fallback은 없다. 전환은 사람이 하고 바꿨다고 말한다.
