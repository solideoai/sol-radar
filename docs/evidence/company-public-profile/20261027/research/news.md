## 확신이 낮은 것

- 일부 quote 는 WebFetch/WebSearch 요약기가 돌려준 원문 발췌다. 페이지를 직접 눈으로 대조하지 못했다. 사람이 인용 문구를 한 번 확인하는 편이 좋다. 특히 news-etnews-2004-jangin 의 quote 는 목록 항목 하나만이다.
- 2024 NIPA 원장상은 회사 수상, 2026 K-SW 그랑프리는 대표 개인 수상으로 읽힌다. 둘 다 홈페이지 제목만 근거라 publicHistory 이고 점수에 쓰지 말 것. 2026 항목의 source quote 는 NIPA 제목이라 항목과 직접 일치하지 않는다(같은 출처 페이지의 다른 줄).
- (정정됨) 1차에서 제외한 ISMP 수주는 2차에서 사실로 확인했다(전자신문 2025-02-16, 디지털데일리 2026-07-10). 단 컨소시엄은 삼성SDS·솔리데오시스템즈·브이티더블유이고 쌍용정보통신은 해당 없다. 1차 검색 요약의 쌍용정보통신은 틀렸다.
- 뉴타닉스 협약 publicHistory 항목은 2차에서 json 에서 뺐다(종류가 맞지 않음). 기술 출처로만 쓴다.
- pp-news-01 이 profile.json 의 세움터와 같은지 불명.

## 2차에서 새로 넣은 것

- 출처 11건 추가(총 16), 실적 4건 추가(총 8), 기술 4건 추가(총 6), 이력 3건(총 3).
- 실적: 차세대 지방행정공통시스템 ISMP(삼성SDS 컨소시엄, 2025-02), 부동산행정정보일원화 사업(국토부 59억, 2013), 마이데이터 종합기반 조성사업 임대차 안심거래(2024), 5차 공공 마이데이터 유통 체계 구축(NIA, 2024). 금액은 모두 null(총액·지분 모름 또는 미공개).
- 기술: 자사 제품만 넣었다. BIM·DXD, JADO(자두), PINO(피노), 마이데이터, ArchiFMS.
- 이력: NIPA 우수상, K-SW 그랑프리, SW기술인상. NIPA 와 K-SW 는 본문 quote 로 교체했다.

## 2차 확신이 낮은 것

- NIPA 항목은 제목이 "원장상" 이고 본문은 "우수상" 이다. json 은 본문 기준 "우수상"으로 쓰고 이름에 제목 표기를 병기했다.
- K-SW 그랑프리는 대표 개인 수상이다. 출처 quote 는 수상 사유 문장 중 제품 설명 부분이다. 사람이 필요하면 수상 사유 문장으로 바꿀 것.
- ISMP 발주기관이 기사마다 다르다(행안부 공모 vs 한국지역정보개발원). 8억원대는 ISMP 총액이고 솔리데오 몫이 아니다.
- 일부 quote 는 가져온 요약기의 발췌다. 2차에 새로 넣은 출처는 기사 페이지를 직접 열어 얻었지만, 글자 단위 대조는 위 6개 외에는 하지 못했다.
- 2021 대통령 표창 기사는 설립연도를 "1988년"으로 적었다(오기로 보임, 다른 기사는 1998). 사용하지 않았다.
