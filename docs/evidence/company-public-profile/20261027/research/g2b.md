## 확신이 낮은 것
- NHN 건 금액은 1차에서 보류했으나 2차에서 나라장터 원문으로 확인했다. 다만 3자단가계약(카탈로그) 표시값이라 실제 지급액과 다를 수 있다.
- 소상공인24(profile.json pp-14) 금액: 기사에 "3차 45억원 규모", "총 152억원 규모"가 있으나 근사치이고 단독·공동수급·계약일·완료일이 없다. 정수 원 단위로 쓰지 않아 JSON 에 넣지 않았다. 컨트롤러가 news 갈래 결과와 합칠 때 note 로 쓸 만하다(1차 약 34억, 2차 약 73억, 3차 45억, 발주 중소벤처기업부).
- 17건 실적 중 금액·날짜를 붙인 것은 0건. 나라장터 직접 조회를 못 한 것이 원인.
- 법인명 혼용(솔리데오/솔리데오시스템즈)은 사업자번호 대조를 못 했다.

## 사람이 할 수 있는 것
1. 브라우저 점유를 풀고 g2b.go.kr 계약현황·개찰결과에서 "솔리데오"(사업자번호 확인 후)로 조회.
2. 나라장터 로그인 후 data.g2b.go.kr 의 "입찰공고 기업별 투찰 및 계약내역" 보고서에서 업체명/사업자번호로 필터해 CSV 저장.
3. 공공데이터포털 조달청 계약정보 Open API 키 발급 후 업체 조회(키 필요).
4. 1차 실적의 발주기관(행안부, 국토부, 식약처, 중기부, 청주시) 계약정보 공개 게시판 확인.
