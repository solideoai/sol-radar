| 확인 | 결과 |
|---|---|
| 칩 줄 | 검색 조건 카드 맨 위, `전체` + 8개(AI·AX·SI·SW·클라우드·데이터·보안·디지털트윈·BIM·유지관리·ISP·ISMP), 기본은 `전체` 눌림 |
| 스위치 | `AI·SI 우선`, 기본 켬. 상세 조건의 `분야` 다중 선택 없음 |
| 정렬 | 기본 `추천순`. 선택지 추천순·최신순·마감 임박순·점수 높은 순·예산 큰 순 |
| IT 범위 | `IT 공고 7건`. IT 밖 3건(건설폐기물·제설장비·행사대행)은 목록에 없다 |
| AI·SI 우선 켬 | AI 묶음(챗봇 82 → 연구용역 미분석) → SI(국방 71) → 나머지(데이터 NO_BID 90 → 미분석 최근 순) |
| AI·SI 우선 끔 | 분석됨 점수 순(82·71), NO_BID 는 분석됨의 끝(90), 다음 미분석 최근 순 |
| 칩 | `AI·AX` → 주소 `keyword=AI_AX`, 2건. `유지관리` 더하면 4건(OR). `전체` → `keyword` 없음 |
| 쪽 넘김 | `/api/v1/opportunities?limit=3` 커서로 끝까지: 우선 켬·끔 둘 다 7건, 겹침·빠짐 없음, 첫 쪽 순서와 같다 |

| 데모 경로 | `?origin=demo` 기본(공고 단계) `IT 공고 15건`, `includeEarly=true` 면 19건(FX 전부) |
| 관심 공고 | IT 밖 공고(건설폐기물)를 담으면 `/watchlist` 에 보인다. 개수 문구는 `사업기회 1건` 그대로 |

| 가로 넘침 | 기본·칩 선택·빈 상태·데모 화면 모두 1440·1280 에서 0px. 칩 줄은 두 폭 모두 카드 안 |
