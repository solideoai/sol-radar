## AI·SI 우선과 고른 정렬(통합 리뷰 L6, `fix/it-scope-empty`)

사용자 결정(2026-10-29): "AI·SI 우선이 켜져 있으면 어떤 정렬이든 묶음 먼저". 전에는 정렬을 직접 고르면 묶음이 같은 값끼리의 순서로만 쓰였다. 이제 `listOpportunities` 는 켬이면 `relevance_rank` → 고른 정렬 → `id`, 끔이면 고른 정렬 → `id` 이고, 커서 식도 같은 순서다.

같은 격리 스택(FX 만)에서 `/bids?origin=demo&sort=publishedAt:desc` 를 analyst 로 열어 확인했다.

| 확인 | 결과 |
|---|---|
| 켬 + 최신순 | 15건이 AI 묶음 3건(10-28·10-26·10-23) → SI 10건 → 나머지 2건 순이고, 묶음 안은 최신순 |
| 끔 + 최신순 | 묶음 없이 게시일 최신순(AI 공고가 1·5·15번째로 흩어진다) |
| 가로 넘침 | 1440·1280 모두 0px |
