## 클라우드 적용 (사용자 승인 2026-10-24)

커밋 `1fd58ff3` 을 main 에 푸시했고 Vercel 배포 상태는 success 다. 클라우드 DB 는 TLS 검증을 유지하고 Supabase 공식 CA(`supabase/prod-ca-2021.pem`, SHA-256 `807025AD…E6CAFA`)를 `NODE_EXTRA_CA_CERTS` 로 줬다.

1. `pnpm db:push -- --check`: 이미 적용 36개, 미적용 14개(20261022000100~20261023000800 의 13개 + 이번 `20261024000100`). 사용자에게 14개 범위를 다시 확인받았다.
2. `pnpm db:push`: 14개 모두 ✓, 적용 완료.
3. `pnpm db:verify`: 연결·마이그레이션 50개·RLS·화면 역할 권한·뷰·함수 확인.

이번 마이그레이션은 데모 조직의 기존 직원 중 메일이 정본과 다른 행이 하나라도 남으면 실패하도록 돼 있고, 실패 없이 적용됐다. 클라우드 행 수를 직접 세는 조회는 `.env.local` 을 읽어야 해 하지 않았다(10-21 기록상 대상 조직 200행).
