# 사이드바 actibooky 톤 (2026-10-28)

사용자가 "사이드바가 아직도 촌스럽다"며 [design.actibooky.com 사이드바](https://design.actibooky.com/components/sidebar)를 참고하라고 했다. 실측값과 비교 시안 세 개(현재·A안·B안)를 보여 주고 사용자가 A안을 골랐다. 결정 기록은 [[16-DECISIONS|ADR-021]] 2026-10-28 3차 개정, 화면 규칙은 [[06-UI-UX|06]] §4.1이다.

## actibooky 실측(1440px, 계산된 스타일)

| 항목 | actibooky | 바꾸기 전 SOL RADAR |
|---|---|---|
| 묶음 이름 | 12px · 굵기 500 · 글자색 70%, 화살표 없음 | 15px · 굵기 600 · 회색, 왼쪽 화살표 16px |
| 메뉴 배치 | 묶음 이름과 같은 왼쪽 선 | 1px 트리 세로선 안쪽으로 들여 씀 |
| 아이콘 | 없음 | 16px, 글자와 같은 검정 |
| 활성 | 옅은 회색 바탕 · 굵기 500 | `sidebar-accent` 바탕 · 굵기 600 |
| 묶음 사이 | 16~20px | 거의 붙음 |

## 바꾼 것 (`web/components/app-shell.tsx`)

- 트리 세로선·들여쓰기 제거. 메뉴가 묶음 이름·맨 아래 고정 칸과 같은 왼쪽 선(사이드바 왼쪽에서 16px)에 선다.
- 묶음 줄: 묶음 이름(`type-caption`, 굵기 500, 회색) 왼쪽, 접기 화살표 14px 오른쪽 끝. 펼친 묶음의 화살표는 마우스·키보드 초점 때만 보이고 접은 묶음의 화살표는 늘 보인다. 접기 기능·`aria-expanded`·`localStorage` 는 그대로다.
- 메뉴 아이콘: `muted-foreground` 70%, 지금 화면·hover 메뉴만 글자색. 받은 초대·맨 아래 고정 칸 아이콘도 같다.
- 활성 굵기 600 → 500(부품 기본값). 바탕은 `sidebar-accent` 그대로.
- 첫 묶음 밖의 묶음은 16px 띄운다. 접은 64px 줄에서는 띄우지 않고 기존 짧은 선만 긋는다.
- 그대로 둔 것: 글자 +3px(ADR-030 B26, 묶음 이름 15px·메뉴 16px), 펼친 상태 아이콘(2차 결정), 묶음 3개와 순서, 로고, 흰 바탕, 64px 아이콘 줄.
