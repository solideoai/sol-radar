# 입찰 일정 `/calendar` (2026-10-28, 파트 C)

스펙: `polaris/specs/done/2026-10-28-gaps-market-calendar.md` §4·§7. 브랜치 `feat/bid-calendar`(기준 `5fa888db`). 사이드바 등록은 통합 때 메인 세션이 한다(그 전에는 주소로 연다).

## 무엇이 보이나

- 월간 달력(KST, 월요일 시작), 이전 달·오늘·다음 달 링크(`?month=YYYY-MM`), 오늘 칸 표시(`aria-current="date"`).
- 일정 종류는 아이콘 + 글자로 구분한다: 폴더 아이콘 = 제출 마감(입찰 프로젝트, 바꾼 값이면 "(변경)"), 문서 아이콘 = 공고 마감, 별 = 내 관심, 보라 글자 "DEMO" = 데모용 가상 공고. 칩의 접근 이름에 종류·시각·관심·DEMO 를 글자로 싣는다.
- 칩은 두 줄이다: 윗줄 종류 아이콘·시각(KST)·별·"DEMO" 글자, 아랫줄 제목(칩 폭 전부). 1440px 에서 제목이 7~8글자 보인다(전에는 아이콘 옆에서 3~4글자). 전체 제목은 마우스를 올리면(title) 보인다.
- 같은 날 2건 이상이면 칸 머리에 겹침 아이콘 + "n건". 칩은 칸마다 2개까지(칸 높이 그대로), 나머지는 "+n건 더" 메뉴. 메뉴는 머리에만 날짜를 두고 항목은 종류 아이콘·시각(HH:mm)·제목(2줄까지)·별·"DEMO" 글자다(접근 이름은 칩과 같다).
- "다가오는 14일" 목록(D-Day·D-n, 오늘 이미 지난 시각은 뺌). 단이 넓으면(사이드바를 편 1440px) 오른쪽, 좁으면(1280px) 달력 아래.
- 보기: 조직 전체(기본, 내 관심 + 조직의 진행 중 프로젝트) / 내 일정(`?view=mine`, 내 관심 + 내가 담당인 프로젝트). 남의 관심은 어느 보기에도 없다(RLS·N3 D6).
- 일정이 하나도 없으면 빈 상태와 "입찰 공고 보기" 링크.
- 마감 알림 안내 문구는 두지 않는다. 운영 알림 Worker 가 기동 전이라 사실이 아니다(`docs/PROGRESS.md` "알림 처리" 행). 회사 Worker 를 켜면 되살린다.

## 일정 모으기 규칙 (`web/server/calendar/calendar.model.ts`)

- 원천: 본인 `bid_watches` + 조직의 `bid_projects`(CLOSED 제외). 새 표·마이그레이션 없음, 사용자 세션 + RLS.
- 프로젝트 제출 마감은 `effectiveDueAt`(변경 값 우선). 변경 값이 없거나 공고 마감과 같은 시각이면 한 건(제출 마감)으로 합치고, 다르면 제출 마감과 공고 마감 두 건이다.
- 같은 공고가 관심이면서 프로젝트이면 프로젝트 일정에 관심 표시만 얹는다(중복 칩 없음).
- 칩 링크: 제출 마감 → `/projects/[id]`, 공고 마감 → `/bids/[id]?origin=demo|live`(공고의 출처).

## 시험

- 단위: `pnpm -C web exec vitest run server/calendar` — 12개 통과. KST 날짜 경계(UTC 15:00 → 다음 날), 마감 없음, 관심+프로젝트 합치기, 제출 마감 변경 두 건·같은 시각 한 건, 조직 전체·내 일정 거르기, 월 칸(5주·6주), 다가오는 14일 경계, `?month` 파싱.
- 변형 확인: 합치기 제거·UTC 날짜·내 일정 거르기 약화·같은 시각 비교 제거·지난 시각 거르기 제거·일요일 시작 6가지 모두 실패(1~2개씩).
- 브라우저: `pnpm -C web exec vitest run --config vitest.browser.config.ts "app/(app)/(work)/calendar"` — 2개(1440·1280) 통과. 256px 사이드바 자리를 비운 본문 폭에서 가로 넘침 0. DEMO 칩에 "DEMO" 글자가 보이고 다른 칩에는 없는지, 제목 줄이 칩 폭을 다 쓰는지(칩 안쪽 폭 − 12px 이상) 잰다. 변형 확인: 칩의 "DEMO" 글자를 빼면 2개 모두 실패, 제목 줄을 반 폭으로 줄이면 2개 모두 실패(48px < 92, 59px < 114). "+n건 더" 메뉴 항목에 날짜가 다시 나오지 않고 제목이 보이는지 잰다. 변형 확인: 항목 시각을 날짜까지 적으면 2개 모두 실패.
