# 자격 갭 레이더 화면 브라우저 시험 증거 (2026-10-28)

> [!warning] 운영 숫자가 아니다
> 이 폴더의 스크린샷은 브라우저 시험이 손으로 만든 mock 데이터로 그린 화면이다. 건수·예산·공고 제목·발주기관은 모두 지어낸 값이고, 운영 실측값과 겹치지 않게 골랐다. 운영 실숫자 화면은 배포 뒤 다시 찍는다.

## 파일

| 파일 | 창 | 이미지 | 상태 |
|---|---|---|---|
| `gaps-1440.png` | 1440×900 | 1152×1772(0.8배) | 관련 업종, 보유 가정 "소프트웨어사업자 신고확인서" 1개를 켠 뒤 |
| `gaps-1280.png` | 1280×800 | 1152×2027(0.9배) | 같은 상태 |

- 한 장에 요약 띠·고정 문구·가정 시나리오 띠·막는 자격 표 10행과 "나머지 2개 업종 보기"·새로 열리는 공고 10행과 "10건 더 보기"·사람 확인 필요 사유가 모두 들어 있다.
- 왼쪽 빈 띠는 앱 틀 사이드바 자리(256px)다. 시험은 본문만 그린다.
- 시험 화면은 Vitest 브라우저 모드의 iframe 이라 한 번 찍으면 문서 높이만큼 나오지만 지금 창 높이만큼만 그려진다. 시험이 창 높이씩 스크롤하며 찍고(`web/test-results/vitest-screenshots/gaps-{폭}.at-{스크롤 위치}.png`), 그려진 부분만 위치대로 이어 붙였다. 이어 붙인 스크립트는 저장소에 두지 않았다.

## mock 데이터

시험 파일: `web/app/(app)/(work)/gaps/gaps-view.browser.test.tsx`

| 항목 | 원래 | 가정(소프트웨어사업자 보유) |
|---|---|---|
| 대상 공고(관련 업종) | 268건 · 1,114.5억 | 같음 |
| 참가 가능(API 기준) | 36건 · 33.8억 | 82건 · 286.8억(+46건 · +253억) |
| 회사 기록 없음 | 74건 · 316.2억 | 28건 |
| 미보유 · 사람 확인 필요 | 0건 · 158건 | 변화 없음 |

- 막는 자격 순위: 소프트웨어사업자(API 1468·1469 합친 행) 46건·253억, 기타자유업종(9999, 사전 밖) 17건·123.5억, 방위산업체(사전 방산업체 지정, 긴 API 코드 목록) 4건·8.2억, 나머지는 "사전 밖 업종 n" 2건씩.
- 새로 열리는 공고 46건: 제목 끝에 "(가상)", 발주기관은 "가상 발주기관 n".
- 정보통신공사업 행은 운영 회사 프로필 r5(정보통신공사업 HELD)와 모순돼 방산업체 지정(`DEFENSE_CONTRACTOR`) 행으로 바꿨다. r5 에 방산업체 기록이 있는지는 운영 DB 를 읽지 않아 확인하지 않았다.

## 시험 명령과 결과

`web/` 에서 실행했다. 브라우저 시험은 무거운 검증 슬롯(`verify-slot.sh`)으로 감쌌다.

| 명령 | 결과 |
|---|---|
| `pnpm exec vitest run --config vitest.browser.config.ts "app/(app)/(work)/gaps/gaps-view.browser.test.tsx"` | Test Files 1 passed · Tests 1 passed, exit 0 |
| `pnpm exec prettier --check "app/(app)/(work)/gaps"` | exit 0 |
| `pnpm exec eslint "app/(app)/(work)/gaps"` | exit 0 |
| `pnpm type-check` | exit 0 |

변형 확인: 막는 자격 설명을 "자격 하나 때문에 참가할 수 없는 공고를…"로 바꾸자 금지어 단언(`/승률|확률|가능성|수주|%|참가할 수 없/`)에서 1 failed, exit 1. 되돌린 뒤 다시 1 passed 였고, 위 스크린샷은 그 깨끗한 실행에서 찍었다.

시험이 보는 것: 요약 띠 글자, 막는 자격 행 순서·칸 글자·스위치 개수, 1440×900 첫 화면에 순위 1~3행, 스위치 → `/gaps?assume=SW_BUSINESS_REG`(스크롤 없이), 가정 띠 원래·가정·차이 숫자와 `aria-live` 알림, 스위치를 켜도 표 위치가 그대로인지, 새로 열리는 공고 링크(`/bids/{id}?origin=live`)·마감 글자, 1280 가로 넘침과 합친 행 칸 넘침, "가정 지우기" 뒤 초점, 순위에서 뺀 미보유 공고 한 줄, 금지어.

보지 않은 것: 실제 서버·DB 와 이어진 화면, 계산 중(pending) 화면, 회사 프로필 없음·대상 0건·오류 상태의 스크린샷.
