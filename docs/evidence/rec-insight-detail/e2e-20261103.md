## 이 확인 뒤 바뀐 것

이 확인은 사전 리뷰 수정 전 코드로 했다. 그 뒤 고친 것(POST 실패 때 팝업 안 [추천 분석], [다시 확인]이 다시 기다림, 누른 요청의 진행률 시작점, 옛 형식 안내문, 같은 이름 자격 짝의 id 순서, 같은 요소 해설 중복 제외)은 브라우저 시험과 gateway 시험으로 확인했다. 실제 앱으로 다시 돌리지는 않았다.
