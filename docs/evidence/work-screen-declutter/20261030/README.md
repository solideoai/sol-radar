- 전체 검증의 첫 시도도 root pre-push 테스트의 로컬 포트 권한 제한으로 중단돼 허용 환경에서 다시 실행했다. 재실행은 exit 0으로 통과했다.

## 캡처와 한계

- [대시보드 1440px](dashboard-1440.png), [대시보드 1280px](dashboard-1280.png): 실제 Chromium 컴포넌트 렌더, 사이드바 폭을 제외한 본문 배치. 전체 AppShell·로그인 세션을 실행한 캡처는 아니다.
- 로그인 후 실제 Supabase·Worker 흐름의 E2E, 실제 분석·결정 저장·운영 배포는 실행하지 않았다. 기존 로그인 E2E의 기대 화면만 새 접기 동작에 맞췄다.
- Vitest 실행 시 설치된 `vitest@4.1.11`과 `@vitest/browser@4.1.12` 버전 차이 안내가 나왔지만 관련 31개 시험은 모두 통과했다. 의존성과 검증 설정은 변경하지 않았다.


## 후속 사용자 수정: 필터 복원·갭 레이더 기술 메타 제거

2026-10-30 사용자 지시로 입찰·관심 공고의 필터를 정리 전 구성으로 복원했다. 분야·출처 빠른 선택, 기관·단계·상태·권고·최종 결정·회사 구분·데이터 구분·정렬이 다시 모두 보인다. 자격 갭 레이더의 회사 프로필 revision과 기준 시각은 접는 대신 표시 자체를 제거했다. 프로필 데이터 성격과 업무 범위 고지는 유지했다. 이 후속 지시가 위 최초 필터 접기 명세와 검증보다 우선한다.

관련 Chromium 3시험 통과(필터 2·갭 레이더 1, 1280·1440px). 갭 레이더 기존 시험은 가정 화면 전환의 pending 종료 전에 결과를 읽던 동기 단언을 결과가 나타날 때까지 기다리는 단언으로 보완했다. 값·기능 단언은 유지했다.

후속 `pnpm verify:changed` exit 0([로그](filter-restore-verify.log)), [브라우저 로그](filter-restore-browser.log). 후속 변경 뒤 전체 빌드·로그인 E2E는 반복하지 않았다. 실행 중 개발 서버에 즉시 반영된다.
