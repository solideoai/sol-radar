# 해커톤 검증 실행 범위 구현·검증

## 변경

ADR-046에 따라 개발 기본 명령 `pnpm verify:changed`를 추가했다. 전체 `pnpm verify`·`verify:quick`·커밋 훅·CI·린트와 필수 검사의 본문은 유지했다. 일반 웹 변경은 웹 quick 1개, 일반 Python 변경은 해당 서비스 검사 1개, 문서 변경은 코드 검사 0개를 선택한다. 전체 quick은 공통 5개 + 웹·AI·결정 서버 3개다. 이 수는 선택한 명령 수이고 시간 절감률이 아니다.

마이그레이션 변경은 DB 정책·타입·웹 검사를 선택한다. 미분류 코드와 검증 설정 변경은 전체 quick으로 넓힌다. AI 프롬프트·PDF 파서 입력·AI/결정 서버 계약·실행 모드 계약·worker wire fixture는 문서로 제외하지 않고 의존 검사를 실행한다.

개발/통합 검증 시점·Compose 실행 조건·중복 검사 제거·통합 리뷰 정책은 [[../../17-CLAUDE-IMPLEMENTATION|17 구현 규칙]] "해커톤 검증 정책"과 [[../../16-DECISIONS|ADR-046]]에 반영했다.

- 최종 범위 선택·실제 Git 변경 수집·CLI 오류/첫 실패 중단 14개 PASS. 기존 게이트 자기 보호 27개와 합계 `node --test scripts/verify-changed.test.mjs scripts/gate-integrity.test.mjs` **41/41 PASS**.
- Superpowers requesting-code-review 방식의 독립 리뷰 1회와 지적 범위 재검토: 네 가지 검사 선택 누락을 수정했고 잔여 지적 없음.
- 첫 `pnpm verify`: **208.92초, exit 1**. 루트 775개 중 770 PASS / 5 FAIL. 기존 `scripts/pre-push.test.mjs`의 localhost listen이 sandbox EPERM으로 차단됐다. 이후 웹·Python 단계는 실행되지 않았다. [원본](20261021-verify.txt).
- 포트 사용 허용 환경의 첫 재실행: 루트 779·웹 6,830·빌드 통과 후 Python 단계 도중 사용자 추가 지시로 중단했다. [축소 전 재실행 로그](20261021-verify-retry.txt).

## 한계

이 변경은 개발 중 검사 범위와 반복을 줄인다. 기존 커밋 게이트의 웹 quick 전체 실행과 전체 verify의 검사 명령은 그대로다. 이후 사용자 추가 지시로 아래와 같이 시험 자체도 축소했다. 시간 절감률과 1~2시간 지연의 전체 원인은 측정하지 않았다. 제품 동작·DB·Compose 설정을 바꾸지 않아 실제 Compose 기동·브라우저·로그인 E2E·실모델 호출은 이번 검증 범위가 아니다.

작업 폴더에는 다른 세션의 랜딩 화면·문서·`.gitignore` 변경도 있다. 이 변경들은 수정하거나 되돌리지 않았으며 전체 verify는 공유 작업 폴더를 읽는다.

## 사용자 추가 지시 — 시험 자체 축소

사용자가 실행 빈도 축소만으로 부족하며 웹 6,830개를 포함해 과도한 시험 자체를 삭제하도록 명시했다. 기존 시험 실패를 숨긴 수정이 아니며, `skip`·탐색 제외·게이트 실행 명령 변경을 사용하지 않았다.

- 웹 단위: 219파일·6,830개 → 23파일·286개. 197파일의 6,549개를 삭제하고 첨부 SSRF/크기/형식의 대표 보안 시험 5개를 남겼다. 골든·권한·수집 멱등·사람 결정 등 281개는 기존 핵심 시험이다.
- 브라우저 컴포넌트: 35파일 → 3파일. 공개 E2E 6파일·기본 인증/업무 E2E 19파일을 삭제했다. 공개45·기본 인증13·업무16개는 수집을 확인했으며 실제 실행 통과 주장과 구분한다.
- 루트: 779개 → 163개, 전체 루트 실행 13.93초. 비핵심 도구 시험 17파일을 삭제했다.
- DB: 8,608줄 → 1,117줄·핵심 21개. 전 표 RLS·조직/운영자 격리·worker 쓰기·역할·복합 FK·사람 결정과 감사/outbox·숨긴 수집 열·view·명부/평가 인력 격리를 보존했다. 마이그레이션을 한 번 적용하고 각 시험은 독립 스냅샷을 복제한다. 단독 21 PASS, 15.92초.
- Python: AI 1,511개 → 핵심100개, 결정 서버152개 → 57개. 시험22파일 삭제 및 6파일의 테스트 함수를 축소했다. conftest의 외부 네트워크 차단은 유지했다. 다른 세션의 신규 Vercel 시험은 삭제하지 않았다.
- [실제 삭제/보존 목록](20261021-pruned-tests.json), [축소 후 전체 verify](20261021-mvp-verify.txt). 전체 `pnpm verify` exit 0: 루트163(13.93초)·웹286(5.20초)·AI101(22.03초)·결정57(0.55초), 서식·타입·린트·계층·토큰·DB 타입·프로덕션 빌드 PASS. AI는 축소한 핵심100 + 다른 세션의 배포 smoke1이다. 두 Python 서비스의 기존 Starlette/httpx deprecation warning은 남아 있다.
